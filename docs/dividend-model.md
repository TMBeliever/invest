# InvestScope 红利量化模型与资产配置策略

本文档说明平台的两大核心算法模型：**7指标红利板块测温仪** 与 **6维度高胜率红利股评分模型**，以及针对 200万资产的**核心-卫星资产配置方案**。

---

## 1. 红利板块测温仪模型

红利板块测温仪用于判断当前整体红利市场的「体温」（0 - 100°C），协助投资者在市场低估时买入、高估时止盈。

### 1.1 指标体系与权重分配

代码实现位置：`packages/data/calculators/temperature.ts`

| 序号 | 指标名称 | 权重 | 判定逻辑 |
|:---:|:---|:---:|:---|
| 1 | **PE 历史百分位** | 25% | 中证红利近 5 年 PE 百分位。百分位越低 = 估值越便宜 = 温度越低 |
| 2 | **股息率溢价** | 20% | 当前股息率 vs 历史中位数。股息率高于中位数越多 = 越便宜 = 温度越低 |
| 3 | **股息/国债收益率比** | 15% | 股息率 / 10年期国债收益率。比值越高（如 >3.0）= 相对债券越具性价比 = 温度越低 |
| 4 | **近60日超额收益** | 15% | 相对沪深300指数超额。跑赢过多说明短线资金拥挤 = 温度升高 |
| 5 | **ETF 资金净流入** | 10% | 近 30 日红利类 ETF 资金流入量。大幅净流入 = 市场偏热 |
| 6 | **成份股破净率** | 10% | 高分红股票中 PB < 1.0 的比例。破净率越高说明整体偏低估 = 温度越低 |
| 7 | **北向资金变动** | 5% | 外资近 30 日增减持比例 |

### 1.2 温度区间与操作建议

```
 0°C                     30°C                    60°C                    80°C                   100°C
 ├───────────────────────┼───────────────────────┼───────────────────────┼───────────────────────┤
 │     FREEZING (极寒)   │       COOL (偏冷)     │      NEUTRAL (中性)   │       WARM (偏热)     │     HOT (过热) 
 │     贪婪区·强力加仓   │     分批买入·良机     │     持有·按月定投     │     减少买入·观察     │   止盈离场·锁定
```

## 2. 高胜率红利股评分与买卖信号模型

针对 A 股全市场或中证红利成份股，从 6 个维度进行打分 (0-100)：

代码实现位置：`packages/data/calculators/dividend-score.ts`

### 2.1 6维打分模型

1. **股息稳定性 (25%)**：连续分红年数 (≥10年满分)、股息年化增长率、分红率波动标准差。
2. **估值安全边际 (20%)**：PE/PB 在近 5 年历史中的百分位。
3. **基本面质量 (20%)**：ROE 3年均值 (≥12%优秀)、ROE 稳定性、毛利率趋势、资产负债率 (<60%安全)、经营现金流/净利润 (>1.0优秀)。
4. **技术面趋势 (15%)**：均线系统 (MA20>MA60>MA120)、MACD 金叉状态、RSI 指标 (超卖区间得分升高)。
5. **历史胜率回测 (15%)**：在当前估值水平下买入，持有 1年 / 2年 / 3年的正收益概率。
6. **机构认可度 (5%)**：北向资金近 30 日持仓变动与公募基金持仓比例。

### 2.2 信号输出规则

- **85 - 100 分**：`STRONG_BUY` (强烈买入)
- **70 - 84 分**：`BUY` (买入)
- **50 - 69 分**：`HOLD` (持有)
- **35 - 49 分**：`SELL` (卖出)
- **0 - 34 分**：`STRONG_SELL` (强烈卖出)

## 3. 200万资产核心-卫星配置策略

针对 200万 资产规模，兼顾安全性（控制最大回撤 < 12%）与增值目标（年化 10%）：

```
┌─────────────────────────────────────────────────────────────┐
│                       总资产 200 万元                       │
├──────────────────────────────┬──────────────────────────────┤
│ 🛡️ 核心仓位 (60% = 120万元)   │  防守打底，稳定现金流 (股息) │
│  - 红利低波 ETF / 优质红利股  │  40万元                      │
│  - 中证红利指数基金          │  30万元                      │
│  - 二级债基 / 固收+          │  30万元                      │
│  - 纯债基金                  │  20万元                      │
├──────────────────────────────┼──────────────────────────────┤
│ 🚀 卫星仓位 (30% = 60万元)    │  进攻增强，捕捉市场 α/β 弹性 │
│  - 宽基指数 (沪深300 ETF)    │  25万元                      │
│  - 行业赛道 (AI/消费/医药)   │  20万元                      │
│  - 港股通优质标的 (恒生科技) │  15万元                      │
├──────────────────────────────┼──────────────────────────────┤
│ 🏦 流动储备 (10% = 20万元)    │  避险 + 极端行情抄底弹药      │
│  - 货币基金 / 现金           │  15万元                      │
│  - 黄金 ETF                  │  5万元                       │
└──────────────────────────────┴──────────────────────────────┘
```

### 动态再平衡机制
- 当任意一类资产偏离目标权重超过 **±5%** 时，系统自动在组合管理页面触发 **再平衡警报**，提示高卖低买。
